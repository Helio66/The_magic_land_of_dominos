# The_magic_land_of_dominos
This repository offers the ability to play dominos in a different ways. 
- To play this game in a console, install dominos_main.py and run it
- To play this game with a better design, install dominos_main.py, partie.py and dominos_ihm.py and run this last file
- To compute statistics about this game, install and run dominos_stat.py
